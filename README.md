# vibeup-accelerometer-features
This is the R pipeline for extracting participant-level features from smartphone-acquired accelerometer data. This pipeline supports the analytic approach underpinning the analyses reported in:
 
Braund, T. A., Bal, D., du Toit, A., Zheng, W.-Y., Duong, B., Nguyen, D., Berk, J., Hoon, L., Cameron, S., Venkatesh, S., Christensen, H., Newby, J., Gupta, S., & Whitton, A. E. (2026). Smartphone accelerometry captures behavioural markers of amotivation and anhedonia in university students [Manuscript submitted for publication]
 
This work is funded in part by the Wellcome Trust [grant number: 303030/Z/23/Z].
